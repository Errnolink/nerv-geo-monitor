# NERV Telemetry Console

A high-precision environmental telemetry terminal for global air quality monitoring and meteorological surveillance, unified under a NERV-native UI.

## Features
- **Real-time AQI Tracking:** Powered by Open-Meteo.
- **Interactive Map:** Built with MapLibre GL JS.
- **Immersive HUD:** Mobile-optimized bottom-sheet layout with a full-screen background map.
- **Hazard Scale:** Dynamically shifting UI themes (including a custom Purple Hazard mode for extreme AQI).
- **Interactive Waveforms:** Pinch-to-zoom and scroll-wheel zooming for historical and forecast data.

## Installation
No installation required. Simply open `index.html` in any modern web browser or host it as a static site.
